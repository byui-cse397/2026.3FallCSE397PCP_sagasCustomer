# Team documents

Documents written by the experience-layer team: our decisions, our proposals to
the sponsor, and our requirements. Upstream never edits this folder, so syncing
with upstream never conflicts here. The shared documents stay where upstream
keeps them: `docs/` at the repository root, and the `.md` files in `apps/web/`
(statement of work, backlog, definitions, README).

| Folder or file                  | What it holds                                                                                                                                                                       |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `decisions/`                    | One-page decision records: what was decided, what else was considered, and why. The statement of work calls this "decide and write it down". Numbered in order: `0001-…`, `0002-…`. |
| `proposals/`                    | Proposals to the sponsor for open choices, with costs. Each one says whether it was approved and links to where.                                                                    |
| `Sagas-Experience-SRS-draft.md` | The software requirements specification, a course artifact. Where it and the statement of work disagree, the statement of work governs.                                             |

To add a document, put it in the right folder and open a pull request; one
teammate's approval merges it, as for any change.
